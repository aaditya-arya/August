Local variable fonts used by `next/font/local` so builds do not need Google Fonts access.

- DM Sans Latin, weights 100–900, normal: `@fontsource-variable/dm-sans@5.3.0` (interface)
- Lora Latin, weights 400–700, normal and italic: `@fontsource-variable/lora@5.3.0` (writing, reading, and headings)

Files come from the packages' `files/` directories at `https://cdn.jsdelivr.net/npm/`.
The accompanying license files are included from those packages. Both fonts use the SIL Open Font License 1.1.
